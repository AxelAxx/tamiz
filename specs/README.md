# specs

GitHub Spec Kit output, one folder per feature named `NNN-short-name` (for example
`001-contracts-and-skeleton`). Each folder holds `spec.md` (what and why, with
Given/When/Then acceptance criteria), `plan.md` (how, plus `research.md`,
`data-model.md`, `contracts/`, `quickstart.md`) and `tasks.md` (small testable tasks).
Produced with the `/speckit-specify`, `/speckit-plan` and `/speckit-tasks` skills; see
`CLAUDE.md` section 7 for the flow and section 11 for the feature list.
