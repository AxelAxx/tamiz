# Contract: leak eval cases with tool messages

**Addendum**: `specs/009-mcp-agent/tool-calling/` (FR-021 … FR-024, research T-R13).

## Dataset `pii-leak-es` v2

`packages/evals/datasets/pii-leak-es.v2.jsonl`, generated by
`pnpm --filter @tamiz/evals generate:datasets` (seeded, never edited by hand). Header line
as v1 with `"version": 2`. v1 cases are carried over unchanged; tool cases are added:

```json
{"id":"pii-leak-tool-0001","model":"tamiz-auto","tags":["tool-result","clinic"],
 "messages":[
   {"role":"user","content":"¿Qué cita tiene el paciente 4411?"},
   {"role":"assistant","content":null,"tool_calls":[{"id":"call_1","type":"function","function":{"name":"get_patient","arguments":"{\"patientId\":\"4411\"}"}}]},
   {"role":"tool","tool_call_id":"call_1","content":"{\"nombre\":\"…\",\"dni\":\"…\"}"}],
 "tools":[{"type":"function","function":{"name":"get_patient","parameters":{"type":"object"}}}],
 "values":[
   {"kind":"PERSON","location":{"kind":"content","messageIndex":2},"start":11,"end":26},
   {"kind":"DNI","location":{"kind":"content","messageIndex":2},"start":35,"end":44}]}
```

Mix (≥ 40 tool cases, ≥ 60 values in tool messages):

| Tag | Where the values are | Kinds |
|---|---|---|
| `tool-result` | only in `tool` message content | DNI, NIE, NSS, IBAN, CREDIT_CARD, PERSON, EMAIL, PHONE |
| `tool-arguments` | only in an assistant call's arguments (strings and numbers) | PERSON, EMAIL, PHONE, DNI |
| `tool-both` | arguments and result, same value repeated | PERSON, DNI, IBAN |

A value's `location` defaults to `{kind: "content", messageIndex}` when only
`messageIndex` is given (v1 shape).

## Scoring

What a provider would receive: every content, every call's arguments and every tool
result of `providerMessages` (anonymized) or of the case's messages (otherwise). A value
leaks when the decision is `route`, the chain has a non-local target, and the value appears
verbatim (NFC) in any of those texts. Unchanged otherwise (spec 007 FR-006, FR-007).

## Metrics and thresholds

| Metric | Threshold | Note |
|---|---|---|
| `leak_rate.<KIND>` | `eq 0` critical, `lt 0.02` PERSON/EMAIL/PHONE | unchanged; now includes tool values |
| `values.tool_messages` | `gte 40` | new: values whose location is arguments or a tool message's content |
| `leak_rate.tool_messages` | reported | leak rate over those values, all kinds |
